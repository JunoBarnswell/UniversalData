# UniversalData Web 设计约束

产品界面以设计器和执行管理为主要工作面。Native 元数据、校验、Catalog 和 Execution 提供实际事实；浏览器维护编辑状态、布局、撤销重做和选中项。示意图中的包与运行记录只用于视觉场景，不作为上线数据。

设计参考：`/workspace/generated_images/exec-c274e0b4-4883-42a6-a9e6-a18e43bb6f0b.png`（设计器）与 `/workspace/generated_images/exec-f0cff28c-e3a7-4cb5-9117-c00eb9442033.png`（执行管理）。实现统一采用设计器的品牌字标；示意图的控制流选中态纠正为实际显示的数据流，账户图标省略，因为本产品无登录。

颜色：背景与面板 #fff，画布 #f8fafb，主文字 #1f2937，次文字 #667085，边线 #e5e7eb，主操作与选中 #087f8c，错误边 #ef4444。字体使用系统 sans-serif 与中文字体回退；页面标题 24–28px/600，面板标题 16px/600，按钮和表单 13px，辅助文字 12px。间距为 4/8/12/16/24px，控件圆角 4px；采用细描边图标。

编辑器由 56px 主导航、64px 编辑工具条、264px 组件栏、画布、324px 属性栏、可收起结果栏和 32px 状态栏构成。内容区域使用面板、行、表格与画布，不增加统计卡片。右侧属性表单由 Native configuration_schema 驱动，表达式、复杂映射和连接引用可编辑，完整校验由 Native 返回。

图节点直接使用 Package 的稳定 ID；数据流边保留 input/output 索引；控制流边保留约束语义。布局通过同一包版本的 protocol-10 layout 保存。移动节点、配置更改、增删边均进入有界撤销栈；保存重载后恢复布局。

执行页使用列表、详情与分页日志。取消、恢复和调试按钮遵循真实状态；提交不明显示“需要恢复”，不自动重试。没有实际执行数据时显示空状态，未验证包显示“尚未校验”，不填入假成功、假吞吐或假日志。

窄屏将组件目录和属性表单改为可切换抽屉，保留主要画布与键盘操作。交互支持明确 focus、表单 label、错误关联以及 reduced-motion。最终验收需完成真实编辑、保存重载、部署、执行、日志、调试和恢复，并比较参考图与实际浏览器截图。
